# UI C — Final Design System Freeze

## Tokens congelados para storefront premium
- Fondo cálido: `--ss-bg`.
- Superficie: `--ss-surface`.
- Tinta principal: `--ss-ink`.
- Texto secundario: `--ss-muted`.
- Acento beauty: `--ss-accent`.
- Acento profundo: `--ss-accent-deep`.
- Línea suave: `--ss-line`.
- Radios: `--ss-radius-sm`, `--ss-radius-md`, `--ss-radius-lg`.
- Sombras: `--ss-shadow-soft`, `--ss-shadow-card`.

## Regla
Toda pantalla nueva o modificada debe reutilizar estos tokens antes de crear estilos aislados.
