# UI D — Visual QA Checklist

## Home

- Header se ve editorial y no genérico.
- Hero tiene alto impacto visual.
- CTA principal es visible.
- Producto destacado se ve protagonista.
- El marquee no rompe layout.
- Lookbook aparece correctamente.

## Catálogo

- Filtros funcionan.
- Grid se adapta desktop/mobile.
- Cards no duplican precio.
- Quick add abre carrito.
- Productos agotados se distinguen.

## Producto

- Galería carga correctamente.
- Variantes se seleccionan.
- Cantidad funciona.
- Add to bag abre carrito.
- Reviews siguen visibles.
- Productos relacionados se muestran.

## Mobile

- Bottom nav visible.
- Header no ocupa demasiado.
- Cards se leen bien.
- CTA táctil es cómodo.
- No hay scroll horizontal.
