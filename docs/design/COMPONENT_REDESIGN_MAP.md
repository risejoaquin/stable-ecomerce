# Component Redesign Map

## Componentes storefront prioritarios

### Header / Navigation
Rediseñar para claridad mobile-first, carrito visible y navegación mínima.

### Hero
Crear hero editorial con CTA, propuesta de valor y apoyo visual.

### ProductCard
Imagen amplia, badge, precio, beneficio corto, CTA y estado hover.

### CategoryCard
Visual clara por categoría/necesidad, no solo texto.

### ProductDetailHero
Galería + info principal + CTA sticky mobile.

### TrustBar
Pago seguro, envío, soporte, devoluciones.

### ReviewSummary
Rating, número de reseñas, confianza.

### CartDrawer / CartPage
Resumen claro, edición rápida, CTA fuerte.

### CheckoutLayout
Formulario simple, resumen persistente, microcopy de confianza.

### CampaignLandingSections
Hero de campaña, producto, prueba social, FAQ, CTA.

## Componentes admin que se dejan fuera de UIX-01
El admin ya está funcional. En esta etapa se prioriza storefront público. Admin polish queda como backlog secundario salvo navegación visual del command center.
