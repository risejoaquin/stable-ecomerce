# UI Implementation Roadmap

## Fase actual: UIX-01
Planeación UX, benchmark, estándares, journey, arquitectura y design direction. No cambia código funcional.

## Macro UI A — Premium Storefront Redesign
Incluye:
- Design system CSS/tokens.
- Header/nav.
- Home.
- Catálogo.
- Product cards.
- Product detail.
- Landing pages.
- Mobile storefront.

## Macro UI B — Checkout & Conversion Experience Redesign
Incluye:
- Carrito.
- Checkout.
- Confirmación.
- Tracking.
- Login/registro.
- Perfil.
- Loyalty/wishlist.
- Error/loading/empty states.
- Final mobile checkout polish.

## Validación por macro
- `npm run build`.
- Smoke frontend manual.
- Revisión mobile.
- Capturas antes/después.
- Checklist de conversión.
- Validación de accesibilidad básica.

## Criterios de aceptación
- La tienda ya no debe sentirse como plantilla básica.
- La home debe comunicar marca y producto en menos de 5 segundos.
- El producto debe ser protagonista.
- El checkout debe sentirse seguro.
- Mobile debe sentirse nativo/cómodo.
- El sistema visual debe ser consistente.
