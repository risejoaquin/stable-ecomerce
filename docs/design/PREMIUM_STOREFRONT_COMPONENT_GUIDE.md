# Premium Storefront Component Guide

## Componentes agregados

- `PremiumHeader.tsx`: navegación superior premium con acciones clave.
- `PremiumHero.tsx`: hero editorial con CTA principal y producto destacado.
- `PremiumProductCard.tsx`: card de producto con imagen protagonista, badge y CTA compacto.
- `PremiumCategoryStrip.tsx`: categorías visuales rápidas.
- `PremiumTrustSection.tsx`: confianza comercial visible.
- `PremiumEditorialSection.tsx`: storytelling educativo/comercial.
- `PremiumProductDetail.tsx`: layout premium para PDP.
- `PremiumLandingSection.tsx`: bloque para campañas.
- `MobileStorefrontNav.tsx`: navegación inferior mobile.

## Tokens base

## Uso recomendado
Esta macrofase deja los componentes premium listos para integración progresiva. La integración definitiva debe hacerse pantalla por pantalla para evitar romper flujos existentes.
