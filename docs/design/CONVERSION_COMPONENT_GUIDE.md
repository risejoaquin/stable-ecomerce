# Conversion Component Guide

## Componentes agregados

- `CheckoutConfidenceStrip`: microcopy visual de seguridad en el carrito.
- `PremiumEmptyState`: estado vacío premium para wishlist, carrito y account.
- `PostPurchaseNextSteps`: próximos pasos después del pago.
- `ConversionMicrocopy`: textos cortos para reducir fricción y dudas.

## Estilos agregados

- `src/styles/checkout-conversion.css`

## Reglas

- No saturar checkout con información innecesaria.
- Mantener CTA principal visible.
- Usar mensajes humanos y directos.
- Priorizar mobile-first.
- Reutilizar tokens visuales de la marca premium.
