# UI C — Conversion Polish

## Principios
- Cada pantalla debe tener un siguiente paso claro.
- La confianza debe aparecer antes del momento de pago.
- El usuario no debe preguntarse qué pasará después de comprar.
- Los errores deben explicar cómo corregirse.
- Los estados vacíos deben sugerir una acción.

## Elementos clave
- CTA principal consistente.
- Beneficios cerca de producto y checkout.
- Envío/devolución visibles.
- Seguridad Stripe/comprador visible.
- Reviews/testimonios cuando existan.
- Recompra y favoritos preparados.
