# Design System Direction — Premium Clean Beauty

## Dirección visual recomendada
Premium Clean Beauty: elegante, clara, cálida, mobile-first y comercial.

## Personalidad visual
- Limpia.
- Premium.
- Confiable.
- Moderna.
- Suave pero con contraste.
- Comercial sin parecer agresiva.

## Paleta sugerida
- Base cálida: ivory / off-white.
- Texto: soft black / charcoal.
- Neutros: sand / beige / stone.
- Acento: rose nude / champagne.
- Éxito: green suave.
- Error: red claro, no agresivo.

## Tipografía
- Títulos: elegante, alto impacto, buen contraste.
- Texto: legible, simple, moderna.
- Botones: claros, consistentes, accionables.

## Componentes base
- Button primary.
- Button secondary.
- Product card.
- Category card.
- Trust badge.
- Price block.
- Review block.
- Input.
- Select.
- Alert.
- Empty state.
- Loading skeleton.
- Sticky CTA mobile.
- Checkout summary.

## Reglas de consistencia
- No más de 2 estilos de botones principales.
- Cards con la misma estructura base.
- Espaciado homogéneo.
- Estados hover/focus definidos.
- Microcopy consistente.
- No saturar con bordes y sombras.
