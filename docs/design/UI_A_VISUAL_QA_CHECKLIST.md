# UI A Visual QA Checklist

## Home
- Hero visible en mobile y desktop.
- CTA principal claro.
- Producto destacado no rompe layout sin imagen.
- Trust badges visibles.

## Catálogo
- Cards con imagen limpia.
- Precio claro.
- CTA táctil en mobile.
- Grid responsive 4/2 columnas.

## Producto
- Galería o imagen principal clara.
- Beneficio/descripción visible.
- Confianza antes de compra.
- CTA sticky disponible en mobile.

## Mobile
- Header no tapa contenido.
- Bottom nav no tapa CTA crítico.
- Touch targets mínimo 44px.
- Espaciado suficiente.

## Performance visual
- Imágenes con `loading="lazy"` donde aplica.
- CSS sin dependencias externas.
- Componentes degradan bien si faltan datos.
