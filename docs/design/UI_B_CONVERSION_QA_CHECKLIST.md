# UI B — Conversion QA Checklist

## Carrito

- [ ] El drawer abre/cierra correctamente.
- [ ] Los productos son legibles en mobile.
- [ ] Los controles de cantidad tienen área táctil suficiente.
- [ ] El subtotal, descuento y total son claros.
- [ ] El checkout invitado comunica por qué pide correo.
- [ ] El CTA de pago se ve como acción principal.
- [ ] La confianza Stripe/seguridad está visible.

## Checkout/post-compra

- [ ] La pantalla de confirmación se siente premium.
- [ ] Hay próximos pasos claros.
- [ ] Existe CTA para seguir comprando.
- [ ] Existe CTA para rastrear pedido.
- [ ] El mensaje reduce ansiedad post-pago.

## Mobile

- [ ] El drawer ocupa ancho completo de forma limpia.
- [ ] Los inputs no quedan pequeños.
- [ ] Los botones tienen altura mínima cómoda.
- [ ] No hay overflow horizontal.
- [ ] La jerarquía visual es clara.

## Conversión

- [ ] El diseño prioriza compra segura.
- [ ] El usuario entiende política/soporte.
- [ ] Los errores usan lenguaje humano.
- [ ] Los estados vacíos invitan a continuar.
