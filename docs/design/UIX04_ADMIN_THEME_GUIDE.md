# UIX04 — Admin Theme Guide

## Objetivo

Alinear el panel de administración con el nuevo tema premium sin volverlo decorativo ni sacrificar claridad operativa.

## Reglas

1. El admin debe verse como una consola de marca, no como Bootstrap/Tailwind default.
2. Las métricas deben seguir siendo legibles antes que decorativas.
3. Los fondos deben ser cálidos, no grises genéricos.
4. Las tarjetas deben usar bordes suaves y sombras ligeras.
5. Los botones principales deben ser oscuros y claros en intención.
6. Las tablas y formularios deben mantener contraste suficiente.

## Componentes afectados por CSS global

- Sidebar admin
- Header admin
- Cards de métricas
- Cards de gráficas
- Cards de auditoría/operación
- Formularios de productos/categorías/settings
- Tablas y listas
- Inputs/selects/textareas

## Criterio de aceptación visual

El admin debe sentirse como parte del mismo producto que el storefront, pero más funcional y menos editorial.
