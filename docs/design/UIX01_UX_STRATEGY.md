# UIX-01 — Premium Storefront UX Strategy

## Estado de partida
Selfcare Sinners ya cerró el roadmap técnico/comercial post-launch hasta PL35. El siguiente cuello de botella no es funcional: es percepción visual, confianza, claridad comercial y conversión.

## Objetivo
Rediseñar la experiencia pública de la tienda para que deje de sentirse como una web básica y evolucione a una experiencia ecommerce premium, mobile-first, confiable y preparada para tráfico comercial real.

## Principios UX
1. Diseñar por intención, no por pantallas aisladas.
2. Reducir fricción antes de agregar complejidad visual.
3. Producto como protagonista.
4. Confianza visible antes del carrito y durante checkout.
5. Mobile-first obligatorio.
6. Microcopy humano, claro y comercial.
7. Componentes consistentes antes de expandir pantallas.
8. Cada cambio visual debe tener una razón: confianza, claridad, conversión o marca.

## Intenciones principales del usuario
- Descubrir productos.
- Resolver una necesidad de skincare.
- Comparar opciones.
- Entender beneficios, ingredientes y uso.
- Sentir confianza antes de pagar.
- Comprar rápido desde móvil.
- Rastrear pedido.
- Volver a comprar.

## Customer journeys prioritarios
### Journey 1 — Descubrimiento orgánico
Home → categoría → producto → carrito → checkout → confirmación.

### Journey 2 — Campaña pagada
Landing page → producto destacado → bundle/oferta → checkout → post-compra.

### Journey 3 — Usuario con necesidad concreta
Búsqueda/filtro → resultados → comparación → producto → compra.

### Journey 4 — Recompra
Cuenta/perfil → pedido anterior → producto → checkout rápido.

## Resultado esperado de UIX-01
Un plan claro para rediseñar la tienda antes de tocar código: referencias, estándares, arquitectura de información, design system y mapa de implementación.
