# UI C — Mobile Checklist

- Header mobile limpio.
- Menú simple y táctil.
- Cards con imagen clara y CTA accesible.
- Product detail con CTA sticky si aplica.
- Carrito fácil de editar.
- Checkout sin ruido visual.
- Inputs con altura mínima de 44px.
- Espaciado suficiente entre elementos táctiles.
- Texto legible sin zoom.
- Trust messages visibles antes de pago.
