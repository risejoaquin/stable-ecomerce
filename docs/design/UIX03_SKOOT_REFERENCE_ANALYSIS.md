# UIX03 — SKOOT Reference Analysis

## Propósito
Usar SKOOT como referencia visual principal para cambiar Selfcare Sinners de una tienda ecommerce básica a una experiencia editorial de marca.

## Patrones observados de la referencia
- Navegación de tienda directa, categórica y editorial.
- Categorías visibles desde el menú principal: shop, new, shop all, coats, tops, hoodies, bottoms, accessories, jewelry, lookbooks y stockists.
- Lenguaje visual con personalidad: uso de tipografía/carácteres distintivos como SHØP y LØØKBØØKS.
- Catálogo con producto directo, precio claro, variantes y estados de sold out.
- Carrito simple con cálculo de shipping/taxes al checkout.
- Fuerte presencia de lookbooks/campañas por año.

## Lo que se adapta a Selfcare Sinners
- Layout editorial y minimalista.
- Menú fuerte y directo.
- Catálogo con protagonismo de producto.
- Secciones tipo lookbook/campaign para skincare edits.
- Tipografía con más carácter.
- Estética menos genérica y más de marca.

## Lo que NO se copia
- Logo, textos, imágenes, productos, estructura exacta, naming, identidad streetwear o símbolos propios de SKOOT.

## Traducción para skincare/beauty
Selfcare Sinners debe tomar la energía editorial de SKOOT, pero orientarla a una tienda de skincare:
- producto limpio y deseable;
- campañas visuales tipo ritual;
- contenido educativo breve;
- confianza de compra;
- mobile-first;
- checkout claro.
