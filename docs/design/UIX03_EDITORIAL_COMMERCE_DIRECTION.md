# UIX03 — Editorial Commerce Direction

## Concepto visual
Dark Clean Beauty Editorial.

## Sensación de marca
- Premium.
- Misteriosa.
- Limpia.
- Editorial.
- Directa.
- Menos plantilla ecommerce.
- Más campaña visual.

## Principios de diseño
1. Menos ruido, más intención.
2. Producto como protagonista.
3. Navegación editorial clara.
4. Imágenes grandes y secciones con ritmo visual.
5. Texto corto, contundente y de marca.
6. Mobile-first como experiencia principal.
7. Confianza visible antes del checkout.
8. Cada pantalla debe parecer parte de una marca, no de una plantilla.

## Paleta recomendada
- Negro suave / carbón.
- Blanco cálido.
- Marfil.
- Nude rosado.
- Gris editorial.
- Acento rojo/vino muy controlado para CTA o marca.

## Tipografía
- Títulos con personalidad editorial.
- Cuerpo limpio y altamente legible.
- Mayúsculas en navegación y labels.
- Microcopy corto.

## Tratamiento visual
- Grids amplios.
- Cards minimalistas.
- Fotografía protagonista.
- Bordes finos o sin borde.
- Sombras casi nulas.
- Uso de blanco/negro con contraste elegante.
