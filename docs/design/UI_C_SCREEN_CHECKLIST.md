# UI C — Screen Checklist

## Storefront público
- Home con hero premium, categorías, destacados, confianza y bloque editorial.
- Catálogo con cards consistentes, filtros legibles y CTA claro.
- Detalle de producto con jerarquía, beneficios, confianza y CTA visible.
- Landing pages listas para campaña con estructura clara.

## Conversión
- Carrito claro y visualmente integrado.
- Checkout con confianza, costos claros y microcopy humano.
- Confirmación de compra profesional.
- Tracking con próximos pasos claros.

## Cuenta cliente
- Login/registro consistente.
- Perfil legible.
- Wishlist/loyalty sin look genérico.

## Legal y soporte
- FAQ, políticas, contacto y devoluciones con lectura cómoda.
