# UI D — Editorial Component Guide

## Componentes nuevos

### EditorialHeader
Header sticky con navegación mínima, logo grande y botón de carrito tipo editorial.

### MobileEditorialNav
Navegación fija inferior para mobile. Reduce fricción para home, shop, edit y carrito.

### EditorialProductCard
Card visual de producto con imagen grande, título display, precio, estado de stock, wishlist y quick add.

### EditorialLookbookSection
Sección tipo campaña/lookbook para que la marca deje de sentirse como catálogo genérico.

### EditorialFooter
Footer editorial con presencia fuerte de marca y enlaces legales/soporte.

## Reglas

- Mantener contraste alto.
- Usar texto corto y con intención.
- Producto siempre protagonista.
- Mobile debe sentirse como app editorial.
- No saturar con demasiados bloques visuales.
