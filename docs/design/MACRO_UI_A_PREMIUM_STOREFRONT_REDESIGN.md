# MACRO UI A — Premium Storefront Redesign

## Objetivo
Transformar el storefront público para que Selfcare Sinners deje de percibirse como una página web básica y se acerque a una experiencia premium beauty/skincare, mobile-first y orientada a conversión.

## Alcance implementado
- Design system visual base en `src/styles/premium-storefront.css`.
- Header premium.
- Hero editorial/comercial.
- Product cards premium.
- Categorías visuales.
- Trust section.
- Bloque editorial de rutina.
- Product detail premium.
- Landing section para campañas.
- Navegación mobile storefront.

## Principios UX
1. Producto como protagonista.
2. Confianza visible antes del checkout.
3. Mobile-first real.
4. Jerarquía visual clara.
5. Menos fricción, más claridad.
6. Estética premium clean beauty.

## Resultado esperado
La tienda debe sentirse más seria, más estética, más confiable y más preparada para tráfico pagado/orgánico.
