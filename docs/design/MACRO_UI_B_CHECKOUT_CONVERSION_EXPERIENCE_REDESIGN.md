# MACRO UI B — Checkout & Conversion Experience Redesign

## Objetivo

Rediseñar la experiencia de carrito, checkout, confirmación, tracking, login/perfil, wishlist/loyalty y estados de conversión para que Selfcare Sinners deje de sentirse como una web básica y se comporte como una tienda premium confiable.

## Alcance

- Carrito lateral premium.
- Checkout confidence microcopy.
- Confirmación post-compra editorial.
- Tracking con jerarquía clara.
- Perfil y wishlist preparados para una experiencia customer-first.
- Estados empty/loading/error/success con tono de marca.
- Mobile checkout polish.

## Decisión visual

Se mantiene la dirección `Premium Clean Beauty`: fondos cálidos, tarjetas suaves, bordes redondeados, tipografía editorial, confianza visible, CTA claro y navegación mobile-first.

## Principios UX aplicados

1. Reducir incertidumbre antes del pago.
2. Hacer visible la seguridad del checkout.
3. Mantener costos y estado de pedido claros.
4. Diseñar para pulgar en móvil.
5. Usar microcopy humano en errores y estados vacíos.
6. Reforzar confianza post-compra.
7. Evitar ruido visual en momentos de conversión.
8. Mantener consistencia con el storefront premium de MACRO UI A.

## Pantallas afectadas

- Cart drawer.
- Checkout success.
- Tracking.
- Wishlist.
- Profile/account.
- Estados globales de conversión.

## Validación visual

- El carrito debe sentirse premium, claro y seguro.
- El CTA de pago debe ser dominante.
- El usuario debe entender qué pasará después de pagar.
- Mobile no debe sentirse apretado ni improvisado.
- La post-compra debe reforzar confianza, no solo mostrar “success”.
