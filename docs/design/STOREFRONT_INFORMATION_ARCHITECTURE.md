# Storefront Information Architecture

## Navegación principal
- Inicio
- Tienda
- Categorías
- Rutinas / Necesidades
- Ofertas / Campañas
- Sobre la marca
- Ayuda / FAQ
- Cuenta
- Carrito

## Home — orden recomendado
1. Header limpio.
2. Hero premium con CTA.
3. Trust bar breve.
4. Productos destacados.
5. Categorías visuales.
6. Bloque educativo.
7. Reviews/testimonios.
8. Beneficios de compra.
9. CTA final.

## Catálogo — estructura
- Header de categoría.
- Filtros.
- Ordenamiento.
- Grid de productos.
- Estados vacíos.
- Recomendaciones.

## Product Detail — estructura
- Galería.
- Info principal.
- CTA.
- Trust block.
- Beneficios.
- Ingredientes.
- Modo de uso.
- Reviews.
- Productos relacionados.

## Checkout — estructura
- Progreso.
- Datos cliente.
- Dirección.
- Resumen.
- Pago Stripe.
- Políticas.
- Confirmación.

## Landing de campaña
- Hero específico.
- Producto/oferta.
- Beneficios.
- Prueba social.
- FAQ breve.
- CTA repetido.
