# UIX03 — Selfcare Sinners Visual Adaptation

## Adaptación de SKOOT a Selfcare Sinners
SKOOT inspira el carácter editorial; Selfcare Sinners debe convertirlo en belleza/skincare.

## Naming visual sugerido
- SHOP -> SHOP / RITUALS / SKINCARE EDITS
- LOOKBOOKS -> EDITS / RITUAL FILES / SKIN NOTES
- NEW -> NEW ARRIVALS / NEW DROPS
- STOCKISTS -> WHERE TO FIND US, si aplica después

## Estructura de navegación propuesta
- NEW
- SHOP ALL
- SKINCARE
- BODYCARE
- ROUTINES
- EDITS
- BEST SELLERS
- ABOUT
- CART

## Home propuesta
1. Hero editorial grande.
2. Frase de marca fuerte.
3. Grid de productos destacados.
4. Categorías visuales.
5. Ritual/editorial section.
6. Beneficios de compra.
7. Reviews/testimonios.
8. CTA final.

## Catálogo propuesto
- Grid minimal.
- Filtros discretos.
- Product cards grandes.
- Precio claro.
- Badge de stock/sold out.
- Variantes si existen.
- Hover editorial.

## Producto propuesto
- Galería grande.
- Nombre, precio, CTA.
- Beneficios principales.
- Ingredientes/modo de uso.
- Envío/devolución.
- Recomendaciones relacionadas.
- CTA sticky mobile.

## Checkout
Mantener claridad, confianza y bajo ruido. No copiar look streetwear en checkout; debe ser limpio y seguro.
