# Accessibility & Responsive Final Checklist

## Desktop

- Header visible y navegable.
- Menú de cuenta abre y cierra correctamente.
- Carrito visible y con contraste correcto.
- Footer accesible.
- Admin command center sin overflow horizontal.

## Tablet

- Grids se reducen sin romper cards.
- Navegación mantiene jerarquía.
- Tablas admin permiten scroll interno o layout compacto.

## Mobile

- No hay scroll horizontal.
- Bottom nav visible.
- Cuenta abre bottom sheet.
- Carrito puede abrir/cerrar.
- Botones tienen área táctil suficiente.
- Formularios son legibles.

## Accesibilidad básica

- Estados focus visibles.
- Botones importantes tienen texto o aria-label.
- Contraste suficiente en textos principales.
- Empty states explican qué hacer.
- Loading states no bloquean sin feedback.
- Error states indican acción posible.
